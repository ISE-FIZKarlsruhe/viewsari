The Viewsari ontology: Description back to ToC

The Viewsari ontology provides a provenance-aware, FRBR-structured formal vocabulary for the Viewsari knowledge graph, which models entity extraction from Giorgio Vasari's Le Vite de' più eccellenti pittori, scultori, e architettori (1568). It integrates the FaBiO bibliographic layer, the DoCO document component vocabulary, PROV-O for extraction provenance, and the W3C Web Annotation Ontology for anchoring mentions to their textual evidence. The ontology distinguishes three representational layers: a bibliographic layer (edition, translation, volume, biography, page and their web manifestations), a structural layer (paragraphs, text chunks, position selectors), and a content layer (extracted entities such as persons, artworks, locations, and co-occurrences, together with their typed mention annotations).
